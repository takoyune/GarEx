# Roadmap

Rule: finish a phase completely before starting the next. Detailed checklists: `04_TASKS.md`.

## Phase 0 - Recon and setup  | Status: DONE
Goal: understand upstream, build it on Windows, inventory formats.
Exit criteria:
- Upstream GARbro pinned in `vendor/` (commit hash recorded in `vendor/README.md`).
- `GameRes`, `ArcFormats`, `Image.Convert`, `Console` build on Windows with documented steps.
- `reference/GARBRO_REPO_MAP.md` verified column filled.
- `docs/10_FORMAT_TRACKER.md` populated with every format from upstream (auto-generated by `tools/`).
- Open questions in `02_ARCHITECTURE.md` answered.

## Phase 1 - Bridge + open/list  | Status: NOT STARTED
Goal: `pip install` (from local wheel) can open archives and list entries via the bridge.
Exit criteria:
- ADR-004 decided with a working spike.
- `garex-bridge.exe` built from `/bridge`, bundled into the wheel.
- `garex.open_archive()`, `Archive.entries()`, `garex.supported_formats()` work.
- Tests pass on at least 3 formats; clean-venv install verified.

## Phase 2 - Extract  | Status: NOT STARTED
Exit criteria: `extract`, `extract_all` work (bridge); progress callback; safe path handling
(no path traversal out of dest); tests on 3+ formats.

## Phase 3 - Convert image/audio  | Status: NOT STARTED
Exit criteria: `convert_image`, `convert_audio`, and `extract_all(convert=True)` work for the
formats GARbro converts; output compared against GARbro outputs.

## Phase 4 - Create / repack  | Status: NOT STARTED
Exit criteria: `create_archive` and in-place replace workflow work for formats GARbro can create;
round-trip test (extract -> modify -> repack -> open in garex AND verify with GARbro) passes.

## Phase 5 - Native ports (ongoing, repeatable)  | Status: NOT STARTED
Process per format: follow `06_FORMAT_PORTING_GUIDE.md`. Priority order:
1. Formats that are simple and common (plain/uncompressed archives, standard image/audio containers).
2. Formats used by popular engines (confirm priority list with the owner before starting).
3. Formats with encryption/compression.
4. Rare/legacy formats (`Legacy/`, `Experimental/`).
Exit criteria per format: differential test 100% identical, tracker updated.

## Phase 6 - Release hardening  | Status: NOT STARTED
Exit criteria: docs site/README quickstart, versioning, CHANGELOG, PyPI test upload verified,
license/credits check (`09_LICENSE_AND_CREDITS.md`).

## Phase 7 - Cross-platform (future, needs owner approval)
Only after enough formats are native. Re-evaluate bridge strategy for Linux/macOS.
